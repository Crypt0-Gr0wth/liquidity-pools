# 2. Coffres ERC-7540

Les coffres asynchrones séparent la demande de dépôt ou de retrait de son exécution finale. Cette séparation permet de traiter une liquidité différée et des files d’attente explicites.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
