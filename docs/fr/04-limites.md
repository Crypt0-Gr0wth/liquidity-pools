# 4. Limites et intégration

L’intégrateur doit gérer l’asynchronisme, les rôles, les chaînes et les décimales. Les contrats ont été lus pour écrire ce parcours ; aucune installation, compilation, exécution ou test n’a été réalisé.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
